Animation

animation is used to create animations on elements
animation property is used to specify the duration and timing of the animation
animation duration is specified in seconds or milliseconds
animation timing function is used to specify the speed of the animation-ease-in/ ease-out.......
animation delay is used to specify the delay before the animation starts
animation iteration count is used to specify the number of times the animation should be played
animation direction is used to specify the direction of the animation
animation fill mode is used to specify how an element should be styled when the animation is not playing
