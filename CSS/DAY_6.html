Transitions

transition enable you to create smooth animations when hovering over elements
transition property is used to specify the duration and timing of the animation
transition duration is specified in seconds or milliseconds transition timing function is used to specify the speed of the animation-ease-in/ ease-out.......
transition delay is used to specify the delay before the animation starts

Transform

use transform property to rotate, scale, skew, or translate an element

transform property is used to specify the transformation of an element
rotate is used to rotate an element
scale is used to scale an element
skew is used to skew an element
translate is used to move an element

Scale

scale is used to scale an element
scaleX is used to scale an element in the x-axis
scaleY is used to scale an element in the y-axis
scaleZ is used to scale an element in the z-axis
scale3d is used to scale an element in 3D space

translate

translate is used to move an element
translateX is used to move an element in the x-axis
translateY is used to move an element in the y-axis
translateZ is used to move an element in the z-axis
translate3d is used to move an element in 3D space
